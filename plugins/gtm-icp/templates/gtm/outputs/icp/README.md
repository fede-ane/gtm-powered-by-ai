# outputs/icp/

What the ICP module writes.

| File | What it is |
|---|---|
| `icp.md` | Who buys now: the core segment, the segments below it, the negative ICP, their words. The source other modules read |
| `buying-group.md` | The roles in the decision and one persona per main role |
| `icp-dossier.html` | One page built from the two files above, to read and share |

Edit the `.md` files, never the page. After a hand edit, run the module's sync command and the page is rebuilt.

These files hold company names and customer quotes. They stay on your machine and out of git. To share the page outside your company, ask for the redacted copy.
